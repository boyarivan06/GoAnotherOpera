## О проекте

**GoAnotherOpera** — десктопное приложение для поиска и прослушивания музыки. Проект реализован как pet-project и демонстрирует использование Go за пределами серверной разработки: связка Go + CGO + Qt6 для создания нативного GUI.

Весь музыкальный контент предоставляется открытым API [Jamendo](https://www.jamendo.com/). Приложение не хранит медиафайлы локально — треки загружаются и воспроизводятся по требованию.

---

## Возможности

| Функция | Описание |
|---------|----------|
| Поиск по авторам | Находит исполнителей по имени |
| Поиск по альбомам | Отображает альбомы выбранного автора |
| Поиск по трекам | Ищет песни по названию |
| Воспроизведение | Запуск и прослушивание треков внутри приложения |

|-----------|------------|------------|

## Требования

Перед сборкой убедитесь, что установлено:

- **Go** версии `1.20` или выше — [go.dev/dl](https://go.dev/dl/)
- **Qt6** с модулями `Core`, `Gui`, `Widgets`, `Multimedia`
- Компилятор C: **GCC** (Linux/macOS) или **MinGW** (Windows) — требуется для CGO

Проверка установки Go:

```bash
go version
```

## Установка

Клонирование репозитория:

```bash
git clone https://github.com/your-username/GoAnotherOpera.git
cd GoAnotherOpera
```

Загрузка зависимостей:

```bash
go mod download
```

## Запуск

Стандартный запуск Go-проекта без предварительной сборки:

```bash
go run .
```

Приложение запустится после компиляции. Для корректной работы требуется активное подключение к интернету.

---

## Сборка

Компиляция в исполняемый файл:

```bash
go build -o goanotheropera
```

Запуск собранного бинарника:

```bash
./goanotheropera
```

Для Windows:

```bash
go build -o goanotheropera.exe
goanotheropera.exe
```

## API

Проект использует **Jamendo API v3.0** для получения информации об авторах, альбомах и треках.

- Документация: [developer.jamendo.com](https://developer.jamendo.com/v3.0)
- Формат ответа: JSON
- Авторизация: Client ID
